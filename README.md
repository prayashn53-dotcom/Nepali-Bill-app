# Nepali Bill

Simple Billing. Smarter Records.

Nepali Bill is a free, lightweight billing and record-keeping web application made for small shopkeepers and businesses. It works in English and Nepali, runs on any modern browser, and is designed mobile-first so you can create bills comfortably on an Android phone.

## What you can do

- Create sales invoices, estimates, sales orders and purchase bills
- Add or remove 13% VAT on any document, with automatic calculation of subtotal, discount, VAT, total, paid and due amounts
- Keep a cashbook of money received and paid, and print receipt and payment vouchers
- Add your shop logo, name, address, phone and optional PAN or VAT number
- Print any bill or voucher, or save it as a PDF using the browser's print option
- View sales reports and management reports for today, this week, this month, this year or all time
- See sales, purchases, estimated gross profit, VAT payable, receivables and payables
- Switch between English and Nepali, and between light and dark mode
- Sign in with an email and password, or with Google, so each account keeps its own records
- Export a full JSON backup and import it on another device

## Privacy

There is no server and no tracking. All records are stored locally in your own browser, and nothing is sent online. Passwords are stored only as salted hashes on your device. Because there is no password reset, please export a backup regularly.

## How to use

Open the website, create an account, enter your shop details in Settings, and start creating bills. You can install it on your phone from Chrome with "Add to Home screen".

## Important note

This application is a free local invoice and record-keeping tool. It is not presented as an IRD-approved electronic billing system. No IRD registration, PAN or VAT number is required to use it. Businesses that must issue officially approved invoices should check the current rules of the Inland Revenue Department.

## Technology

Built with plain HTML, CSS and JavaScript in a single file. No frameworks, no backend and no paid services.
